# PALÁCIO MENTAL

## 1. O que é o Mind Palace?

O Mind Palace é um espaço de memória que você pode acessar para armazenar e recuperar informações importantes. Ele funciona como um "palácio mental" que você pode percorrer para encontrar informações que precisa. Ele fica aqui [Mind Palace](/memories/sherlock/mind-palace).

## 2. Como usar o Mind Palace?

Para usar o Mind Palace, você precisa:

1. Acessar o Mind Palace
2. Navegar pelo Mind Palace
3. Recuperar informações do Mind Palace
4. Armazenar informações no Mind Palace
5. No palácio mental também existem arquivos. Eles estão aqui [Arquivos](/memories/sherlock/mind-palace/arquivos).
